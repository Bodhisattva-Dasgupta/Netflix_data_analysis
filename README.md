**Movie Data Analysis Using Python**

Project Overview:
This project explores movie data using Python to identify patterns in movie genres, audience ratings, popularity, and release years. It involves data cleaning, exploratory data analysis (EDA), and data visualisation to understand trends in the movie dataset.

Objectives:
Clean and prepare the movie dataset for analysis.
Identify the most frequent movie genres.
Explore the distribution of audience ratings.
Identify movies with the highest and lowest popularity scores.
Analyse movie release patterns across different years.
Visualise findings using charts and graphs.

Tools and Technologies
Python – Data analysis and processing
Pandas – Data manipulation and cleaning
NumPy – Numerical computing
Matplotlib – Data visualisation
Seaborn – Statistical visualisation
Jupyter Notebook – Interactive analysis

Project Workflow:

1. Data Loading and Exploration
Loaded the movie dataset using Pandas and examined its structure, columns, summary statistics, and duplicate records.

2. Data Cleaning and Preprocessing
Converted release dates into year values.
Removed unnecessary columns.
Handled missing values.
Split movie genres into individual categories using string operations and the explode() function.
Converted the Genre column into a categorical data type.

3. Exploratory Data Analysis
Explored genre frequency, audience rating distributions, movie popularity scores, and yearly release patterns.

4. Data Visualisation

Used Matplotlib and Seaborn to create visualisations that help identify genre distributions and trends in movie releases.
Key Findings
Most frequent genre: Drama was identified as the most frequent genre in the dataset.
Popularity analysis: Spider-Man: No Way Home was identified as the movie with the highest popularity score in the dataset.
Lowest popularity: The United States vs. Billie Holiday and Threads were identified as movies with the lowest popularity scores.
Release-year analysis: The notebook identifies 2020 as the year with the highest number of movie releases.
